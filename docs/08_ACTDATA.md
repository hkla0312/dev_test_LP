# ACT DATA Specification

## Definition

ACT DATA is not a normal profile. It is an activity record that grows through Signal and audience reactions.

## ACT DATA Fields

- name
- role
- icon
- Observer Rank
- Signal total
- operator comment
- self comment
- embed video URL
- X URL
- Video URL
- Music URL
- approved Signal comments

## Role Badge Colors

- regular: red glow
- fresh: green glow
- organizer: gold glow

DANCHO organizer is fixed at the last displayed position.

## Comments

LP and Member views display approved Signal comments. Comments should be short chips or small cards to avoid visual pressure.

## Observer Rank

Displayed for ACT DATA only. It indicates how much the ACT has been observed/supported.

Do not confuse with Member Rank.

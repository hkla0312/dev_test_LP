# Sprint 04 — Member Terminal

## Goal

Build the first HTML/CSS/JS implementation of Member Terminal.

## Scope

- Observation Chamber
- Member Rank / Observation Progress
- Today's Signal
- Signal count
- Additional Signal
- Next LIVE
- Your Signal reload
- Archive slide-out
- Settings sound toggle
- How To modal
- Daily Login toast

## Out of Scope

- SEND SIGNAL form
- LIVE DANMAKU
- Achievements
- Gallery
- Secret logs
- Firebase integration

## Acceptance Criteria

- `LA_OS/index.html` opens standalone.
- Mobile layout is primary.
- Your Signal reload changes displayed past Signal.
- Archive unlocked item can slide open.
- How To modal explains each item in plain Japanese.
- No EXP label appears in user-facing UI.

# Decision Log

## DL-001 — Project Name

**Decision:** Project name is LegendaryApocalypse OS / LA_OS.  
**Status:** Accepted

## DL-002 — Product Direction

**Decision:** This is a platform/OS, not just an event website.  
**Status:** Accepted

## DL-003 — ACT DATA

**Decision:** 出演者情報はACT DATAと呼ぶ。プロフィールではなく活動データ。  
**Status:** Accepted

## DL-004 — Signal

**Decision:** 応援コメント/リアクションはSignalとして扱う。  
**Status:** Accepted

## DL-005 — Observer Rank

**Decision:** Observer Rank is for ACT DATA. Member growth is separate.  
**Status:** Accepted

## DL-006 — Member naming

**Decision:** 会員向け表記はMember。Observerは到達点として温存。  
**Status:** Accepted

## DL-007 — Observation Chamber

**Decision:** Member TerminalにObservation Chamberを配置する。意味は説明しすぎない。  
**Status:** Accepted

## DL-008 — Pixel Art

**Decision:** Observation Chamber water tank and entity use pixel art for consistency and implementation cost.  
**Status:** Accepted

## DL-009 — No EXP UI

**Decision:** User-facing UI does not show EXP. Internal value only.  
**Status:** Accepted

## DL-010 — Signal Limits

**Decision:** Signal send limit is 10 per event; daily progress gain limited to 5.  
**Status:** Accepted

## DL-011 — Comment Length

**Decision:** Signal message length is 30 characters.  
**Status:** Accepted

## DL-012 — Additional Signal

**Decision:** Rank Up grants Additional Signal +3; it grants no progress.  
**Status:** Accepted

## DL-013 — Archive Unlock

**Decision:** Archive is unlocked per member by Admin. Unlock grants internal +5.  
**Status:** Accepted

## DL-014 — Money-independent Progress

**Decision:** Merch/booth action grants fixed participation value, independent of amount spent.  
**Status:** Accepted

## DL-015 — Member Terminal Simplification

**Decision:** Remove notifications, gallery, secret logs, quick signal, and danmaku on/off from Member Terminal.  
**Status:** Accepted

## DL-016 — Your Signal

**Decision:** Your Signal randomly displays one past Signal with reload button.  
**Status:** Accepted

## DL-017 — Admin Clarity

**Decision:** Admin UI prioritizes clear Japanese labels over lore terms.  
**Status:** Accepted

# LIVE DANMAKU Specification

## Purpose

LIVE DANMAKU displays approved or live Signal comments on venue screens as flowing comments.

## Assumption

Users are not expected to interact heavily during performances. Main usage occurs before/after the live or during breaks.

## Submission

Signal comments are sent to individual ACTs.

- emoji / reaction
- comment max 30 characters
- target ACT

## Display View

LIVE DANMAKU VIEW should be optimized for venue display / browser full screen / OBS capture.

## Display Rules

- Flowing comments appear as danmaku.
- Comments can show target ACT context.
- Member level may affect color/effect in future.
- Avoid overly noisy display.

## Moderation

Production must include admin moderation or event-safe controls.

## Future Discussion

LIVE DANMAKU needs further UX design around:

- why customers want to participate
- how performers can react
- how comments become meaningful after the live
- how to balance fun with operation burden

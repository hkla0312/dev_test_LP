# Archive Data Specification

## Purpose

Archive Data provides special past live records to unlocked Members.

## Access Model

Archive is locked by default. Unlock is performed by Admin per member account.

```text
Admin
↓
Select Member ID
↓
Select Archive
↓
Unlock
↓
Member view displays unlocked archive
```

## Member UI

- Locked archive: LOCKED label and disabled state
- Unlocked archive: UNLOCKED label
- Tap/click expands slide-out area
- Embedded video appears

## Reward

Archive unlock grants internal +5.

User does not see EXP value. Observation Chamber may subtly react.

## Notes

Archive should feel special, not like a normal video list.

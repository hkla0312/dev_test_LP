# PRD — LegendaryApocalypse OS

## Objective

LegendaryApocalypse OSは、ライブイベントの告知・参加・応援・記録・アーカイブを一つの体験として接続するWebプラットフォームである。

## Target Users

### 来場者 / Member
- ライブ前にイベント情報を確認する。
- ACT DATAを見て出演者を知る。
- Signalを送り、応援の痕跡を残す。
- Archiveを閲覧する。
- Member Terminalで自分の観測記録を振り返る。

### 出演者 / ACT
- ACT DATAに自分の活動や反応が蓄積される。
- Signalやコメントにより、応援の痕跡が可視化される。

### 運営 / Admin
- イベント情報を管理する。
- ACT DATAの基本情報を管理する。
- Signal承認、Archive解禁、Member管理を行う。

## Core Value

- ただ観るだけで終わらない。
- コメントや応援がACT DATAとMember Terminalに蓄積される。
- ライブ後もサイトを開く理由がある。

## MVP Scope

### LP
- EVENT INFO
- ACT DATA
- SHARE POST / SEND SIGNAL導線
- ARCHIVE DATA LOCKED
- LIVE DANMAKU LOCKED
- JOIN THE ACT

### Admin
- Event管理
- ACT基本情報管理
- Flyer画像アップロードUI
- Archive unlock管理
- Signal承認

### Member Terminal
- Observation Chamber
- Member Rank
- Today's Signal
- Signal count
- Additional Signal
- Next LIVE
- Your Signal reload
- Archive unlock view
- Settings sound toggle
- How To modal

### SEND SIGNAL
- ACT選択
- Reaction選択
- 30文字コメント
- 1公演10回まで送信
- 1日5回までProgress加算
- Additional Signal利用

## Non-goals for v1

- Native App化
- 完全なSNS機能
- フォロー/DM機能
- ランキング機能
- 複雑な育成ゲーム化
- リアルタイム投票ランキング

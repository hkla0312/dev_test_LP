# LP Specification

## Purpose

LP is the public entry point. It should make visitors feel that something unusual and interesting is happening, while still letting them find event and reservation information quickly.

## Sections

1. Boot Sequence
2. Hero
3. EVENT INFO
4. ACT DATA
5. SHARE POST / SEND SIGNAL introduction
6. LIVE DANMAKU LOCKED
7. ARCHIVE DATA LOCKED
8. JOIN THE ACT

## EVENT INFO

- Event title
- Date
- Venue
- Open/Start
- Flyer thumbnail
- Tap/click flyer to enlarge
- Reservation button
- Streaming ticket button

## ACT DATA

- Max display 5 cards in current rule:
  - regular 3 random
  - fresh 1 random
  - organizer 1 fixed last (DANCHO)
- VIEW ALL ACT opens modal.
- Card includes icon, role badge, Observer Rank, Signal, comments, SNS links.

## Locked Modules

LIVE DANMAKU and ARCHIVE DATA may appear as red LOCKED modules until member system is ready.

## Responsive

- Desktop: grid-based module layout.
- Mobile: hamburger menu and stacked sections.
- Smooth scroll navigation.

# LA_OS Docs Pack

This package contains the GitHub-ready `/docs` directory for LegendaryApocalypse OS.

## How to use

1. Copy `/docs` into the LA_OS repository root.
2. Treat `docs/00_ProjectBible.md` as the parent document.
3. Use `docs/16_DecisionLog.md` as the source for accepted design decisions.
4. Give Codex relevant docs before each implementation sprint.

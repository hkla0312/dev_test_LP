# 01. Product Specification

## プロダクト名
**Legendary Apocalypse Official LP**

## 目的
Legendary Apocalypseを初めて知る来場者・アーティスト・関係者に対し、以下を短時間で伝える。

- イベント概要
- 次回公演情報
- チケット予約導線
- 掲載アーティスト情報
- DANMAKUの概要
- LA_OSの概要と登録導線
- Official Xおよび問い合わせ導線

## 初版ページ構成
1. HEADER
2. HERO / EVENT INFORMATION
3. ARTIST
4. DANMAKU HIGHLIGHT
5. LA_OS
6. CONTACT
7. FOOTER
8. 右下固定 TOPボタン

## HEADER
- Legendary Apocalypse横長ロゴ
- `CONNECT. CREATE. EVOLVE.`
- ナビゲーション
  - EVENT
  - ARTIST
  - DANMAKU
  - LA_OS
  - CONTACT
- `PROJECT STATUS : ONLINE`
- スマートフォンではハンバーガーメニュー

## HERO / EVENT INFORMATION
- `CONNECT. CREATE. EVOLVE.`
- Legendary Apocalypseロゴ
- キャッチコピー  
  **最期に向かう、そのすべてをー。**
- `PROJECT STATUS : ONLINE`
- 次回公演情報
  - 公演タイトル
  - 日付
  - 会場
  - OPEN
  - START
  - チケット料金
  - フライヤー画像
- 外部予約フォームへ移動するボタン
- ボタン文言は `TICKET RESERVE`

## ARTIST
- セクション名は **ARTIST**
- 日本語説明では「アーティスト」と表記
- DANCHOを固定表示
- その他の登録アーティストからランダム5組
- 合計6組表示
- `VIEW ALL ARTISTS` で全登録アーティストを一覧表示
- カードをタップするとプロフィールモーダル表示

## DANMAKU HIGHLIGHT
- 名称は **DANMAKU**
- 一行の自動横スクロールサンプル
- 現行6種類の絵文字
- 英語コメント中心
- 実際の会場スクリーンの雰囲気を簡略再現

説明文:
> 会場スクリーンへ、感情とコメントをリアルタイムで届けるライブ参加システム。

補足:
> LA_OSメンバーズページでの機能になります。

`詳細はこちら` からLA_OSセクションへスムーズスクロール。

## LA_OS
- 初期状態はコンパクトなカード
- タップで下方スライド展開
- 再タップで閉じる
- モーダルではなくアコーディオン形式

コピー:
> Legendary Apocalypseと共に育っていくメンバーズ機能。

展開内容:
- ライブの簡単予約と予約内容の変更
- DANMAKU投稿
- 推しのアーティストへメッセージ送信
  - 送信したメッセージはアーティストページにも掲載
- 過去ライブ映像をフルで視聴
  - 会場でのライセンス購入が必要
- ユーザーごとにアップデートされるメンバーページ
  - 現在準備中

導線:
- LA_OS詳細ページ
- LA_OS登録フォーム

## CONTACT
- Official X
- 問い合わせフォーム

問い合わせフォーム用途:
- 一般のお客様からの問い合わせ
- アーティストからの出演希望

出演希望アーティスト向け案内:
- アーティスト名・活動名
- 活動しているSNS
- YouTube等の動画URL
- 可能であればライブ映像URL
- 可能であれば音源URL
- プロンプター使用の有無
- その他の活動内容や補足

## 初版対象外
- NEWS
- 更新履歴
- 過去公演一覧
- 支援者向けARCHIVE
- アーティスト個別ページ
- 管理画面
- LA_OS本体機能

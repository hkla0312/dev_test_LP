# 03. ARTIST Specification

## 表記
- 英語: `ARTIST`
- 日本語: `アーティスト`
- `ACT` 表記は禁止

## TOP表示
- DANCHOを固定表示
- その他の対象アーティストからランダム5組
- 合計6組
- リロードごとにランダム選出
- 同一表示内で重複禁止

## VIEW ALL ARTISTS
- 全登録アーティストを一覧表示
- モーダルまたは同ページ内展開
- 個別ページは初版では作成しない

## アーティストカード
表示:
- image
- name
- role
- shortDescription
- firstAppearance
- regular
- organizer

操作:
- クリックまたはタップでプロフィールモーダル
- ページ遷移なし

## プロフィールモーダル
基本情報:
- アーティスト画像
- 名前
- ロール
- プロフィール
- SNS / Video / Music

SIGNAL DATA:
- `song` : 歌が良い
- `stage` : ステージが良い
- `character` : キャラが良い

表示:
- ドーナツグラフ
- 割合
- 件数
- 合計シグナル数

コメント:
- LA_OSメンバーから送信されたアーティスト宛コメント
- ハッシュタグ風表示
- 最大5件
- 長文は省略表示

## ランダム表示ロジック
1. `fixedTop = true` のアーティストを1名取得
2. `visible = true` の対象アーティストから固定対象を除外
3. ランダム化
4. 5名取得
5. 固定1名と合わせて6名表示

## データ不足時
- 6名未満なら登録済み人数分だけ表示
- 空枠は出さない
- 0名の場合は `ARTIST DATA PREPARING`

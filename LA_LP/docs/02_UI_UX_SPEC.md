# 02. UI / UX Specification

## デザインコンセプト
- スマート
- ダーク
- OS / Device / Terminal
- 高視認性
- 装飾は控えめ
- 世界観は強く、情報は読みやすく

### LA_OSとの関係
- LA_OSはピクセル調
- LPはピクセル調に寄せすぎない
- カラー、ステータス表示、端末感で世界観を接続
- LPは洗練されたブランドサイトとして設計

## カラー
- Background: `#050608`
- Panel: `rgba(12, 17, 27, .72)`
- Panel Strong: `rgba(18, 25, 38, .84)`
- Primary Cyan: `#38F5FF`
- Secondary Blue: `#5BA8FF`
- Accent Magenta: `#FF4EDB`
- Accent Violet: `#9D70FF`
- Success: `#6BFFB0`
- Text: `#F5F8FC`
- Sub Text: `#92A3BE`

## フォント
- 英語見出し: Orbitron系
- 日本語本文: Noto Sans JP
- 補助UI: Inter
- ロゴは画像素材

## 画像使用
使用:
- ヘッダーロゴ
- メインロゴ
- ヒーロービジュアル
- アーティスト画像

使用しない:
- ボタン画像
- カード画像
- ナビゲーション画像
- HUD装飾画像

UIパーツは原則CSSで構築する。

## レスポンシブ
### PC
- コンテンツ最大幅: 1280px前後
- ARTIST: 6列
- HERO: 2カラム

### タブレット
- ARTIST: 3列

### スマートフォン
- ARTIST: 2列
- HERO: 1カラム
- ナビゲーション: ハンバーガー
- タップ領域: 44px以上
- モーダル: 縦スクロール対応

## アニメーション
使用:
- ローディング
- セクションフェードイン
- カードの軽い浮き上がり
- ボタンのライン発光
- DANMAKU横スクロール
- LA_OS下方スライド
- TOPボタンのフェードイン

使用しない:
- 過度なグリッチ
- 常時点滅
- 読みづらくなる強い発光

## ローディング
- 1日1回のみ表示
- 同日中のリロードでは非表示
- 翌日リセット
- localStorage使用
- 表示時間は約1〜1.5秒

## ARTISTモーダル
- カードタップで開く
- 背景タップで閉じる
- ×ボタンで閉じる
- Escキーで閉じる
- モーダル中は背景スクロール禁止

表示内容:
- アーティスト画像
- 名前
- ロール
- プロフィール
- SIGNAL DATA
- 受信コメント
- X
- YouTube
- Music

## SIGNAL DATA
集計項目:
- 歌が良い
- ステージが良い
- キャラが良い

グラフ:
- 円グラフまたはドーナツグラフ
- 3項目の比率
- 0件の場合は `NO SIGNAL DATA`
- 数値とラベルを併記

受信コメント:
- LA_OSメンバーから受け取ったコメント
- ハッシュタグ風のチップ表示
- 最大5件程度

## TOPボタン
- ページ右下固定
- 丸型
- 上向き矢印
- `TOP`
- 一定量スクロールすると表示
- タップでページ上部へスムーズスクロール
- モーダル表示中は非表示

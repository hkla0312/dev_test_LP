# 04. Screen Specification

## 1. ログイン

- 管理者ID
- パスワード
- ログイン
- エラー表示
- ログイン中表示

## 2. イベント

### 一覧
- 開催予定
- アーカイブ済み
- 開催予定は開催日順
- アーカイブは折りたたみ

### 編集項目
- タイトル
- 開催日
- 会場
- OPEN
- START
- 前売料金
- 当日料金
- 配信料金
- フライヤー
- ツイキャスURL
- LP公開ON/OFF

### アーティスト追加
- 「アーティストを追加」で登録済み一覧を表示
- 一覧から追加
- 重複追加禁止
- 未登録時は名前だけ簡易登録可能
- 簡易登録時にART-XXXXを自動採番
- 詳細は後からアーティスト画面で編集
- イベント内のアーティスト順はドラッグ&ドロップ

### フライヤー
- 1イベント1枚
- PNG / JPG / WebP
- 差替時は旧画像削除
- プレビュー表示

### アーカイブ
- 物理削除しない
- LP非表示
- Adminで閲覧・復元可能

## 3. アーティスト

### 一覧
- ARTキー
- 名前
- ロール
- 出演回数
- LP掲載
- SIGNAL総数
- レベル
- 情報未入力表示

### 編集
- 名前
- アイコン画像
- プロフィール掲載文
- X
- YouTube
- SNS1
- SNS2
- LP掲載ON/OFF
- fixedTop

### 画像
- 正方形トリミング
- プレビュー
- 保存確認
- 旧画像削除

### 出演回数・ロール
- EVENTとの紐付け数から自動集計
- 1〜2回: ARTIST
- 3回以上: REGULAR
- 手動変更不可

### レベル
- SIGNAL総数からB段階型で算出
- signalTotalは上限なし
- 表示はv0.01〜v1.00

## 4. メンバー

### 一覧選択
クリック / タップで登録済み一覧を表示。

表示:
- MEMBER ID
- 表示名
- PROGRESS
- ライセンス
- アカウント状態

### 詳細
- MEMBER ID
- 表示名
- PROGRESS
- ライセンス
- 登録方式
- XまたはMAIL
- 来場履歴
- 登録日
- 最終更新
- アカウント状態

### パスワード
- 実際の値は表示しない
- 設定済み表示
- 将来、再設定メール送信を追加可能

### ライセンス
- NONE
- STANDARD
- PREMIUM

権限:
- NONE: アーカイブ不可
- STANDARD: 直近3公演
- PREMIUM: 全公開アーカイブ

変更前に確認ダイアログを表示。

## 5. PROGRESS

### 操作
1. メンバーを一覧から選択
2. ポイントを選択
3. 理由を選択
4. 承認
5. 確認ダイアログ
6. 付与

### プリセット
- +10
- +30
- +50
- +100
- +300
- +500

### 任意入力
- 正の整数
- 上限は設定値として管理

### 理由
- 来場
- ライセンス購入
- 物販
- イベント特典
- 運営調整
- その他

## 6. SIGNAL

### 選択
アーティスト一覧から選択。

### 表示
- MEMBER ID
- 表示名
- 種別
- コメント
- 送信日時

種別:
- song: 歌が良い
- stage: ステージが良い
- character: キャラが良い

### 操作
- 閲覧
- 論理削除
- 削除済み表示切替
- 復元

Adminでは件数・割合グラフを表示しない。

## 7. 変更履歴

### 表示
- 日時
- 管理者
- 操作種別
- 対象
- 詳細

### 記録対象
- イベント保存
- イベントアーカイブ
- イベント復元
- アーティスト保存
- PROGRESS付与
- ライセンス変更
- SIGNAL削除
- SIGNAL復元

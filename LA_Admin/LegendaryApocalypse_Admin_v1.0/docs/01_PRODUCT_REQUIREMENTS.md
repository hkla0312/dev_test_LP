# 01. Product Requirements

## 1. 目的

Legendary Apocalypseの運営データを一元管理し、Official LP・LA_OSへ反映する。

## 2. 管理対象

### イベント
- タイトル
- 開催日
- 会場
- OPEN
- START
- 前売料金
- 当日料金
- 配信料金
- フライヤー画像
- ツイキャスURL
- LP公開ON/OFF
- アーティスト紐付け
- アーカイブ / 復元

### アーティスト
- ART-XXXX自動採番
- 名前
- アイコン画像
- プロフィール掲載文
- X
- YouTube
- SNSリンク1
- SNSリンク2
- ロール
- LP掲載ON/OFF
- fixedTop
- 出演回数
- SIGNAL総数
- レベル表示

### メンバー
- MEM-XXXXXX自動採番
- 表示名
- PROGRESS
- ライセンス
- 登録ID種別
- XまたはMAIL
- 来場履歴
- アカウント状態

### PROGRESS
- メンバー選択
- プリセットポイント
- 任意ポイント
- 理由
- 承認
- 履歴保存

### SIGNAL
- アーティスト選択
- 送信者
- SIGNAL種別
- コメント
- 日時
- 論理削除
- 復元

### 変更履歴
- 主要操作のみ記録
- 差分全文は保存しない
- 読み取り専用

## 3. 初版で実装しないもの

- ダッシュボード
- SITE SETTINGS
- CONTENT
- Assets Manager
- CSV出力
- 分析画面
- 複数管理者ロール

# 03. UI / UX Specification

## 1. テーマ

### Light
- 標準テーマ
- 背景: 白〜ライトグレー
- カード: 白
- 文字: ダークグレー
- 主アクセント: シアン

### Dark
- ダークネイビー
- カード: 濃紺
- 文字: 白
- 主アクセント: シアン

テーマ切替状態はlocalStorageへ保存する。

## 2. レイアウト

- 左サイドバー
- 上部ヘッダー
- 右側メイン作業領域
- PCを主軸
- タブレットではサイドバー縮小
- スマホではサイドバーをドロワー化

## 3. ヘッダー

- 現在画面名
- テーマ切替
- 管理者表示名
- ログアウト

## 4. 共通UI

- 新規登録
- 保存
- アーカイブ
- 復元
- 削除
- 取消
- 一覧から選択
- 確認ダイアログ
- 成功 / 失敗トースト
- 読み込み表示
- 空状態表示

## 5. 選択UI

手入力検索を基本にしない。

クリックまたはタップで登録済み一覧を開き、対象を選択する。

対象:
- イベントへのアーティスト追加
- メンバー選択
- PROGRESS対象メンバー
- SIGNAL対象アーティスト

必要な場合のみ一覧内に絞り込み欄を置く。

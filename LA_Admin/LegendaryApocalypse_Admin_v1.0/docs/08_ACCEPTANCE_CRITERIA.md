# 08. Acceptance Criteria

## 認証
- [ ] 未ログイン時はログイン画面
- [ ] 管理者のみアクセス可能
- [ ] ログアウト可能

## テーマ
- [ ] Lightが標準
- [ ] Darkへ切替
- [ ] 再訪問時も維持

## イベント
- [ ] 新規登録
- [ ] 編集
- [ ] 1枚のフライヤー
- [ ] アーティスト一覧から追加
- [ ] 名前だけ簡易登録
- [ ] 重複追加禁止
- [ ] 並び替え
- [ ] アーカイブ
- [ ] 復元
- [ ] LP公開切替

## アーティスト
- [ ] ARTキー自動採番
- [ ] 正方形トリミング
- [ ] SNS編集
- [ ] LP掲載切替
- [ ] 出演回数自動集計
- [ ] 3回以上でREGULAR
- [ ] SIGNAL総数保持
- [ ] 段階型レベル表示
- [ ] 保存確認

## メンバー
- [ ] MEMBER ID表示
- [ ] 表示名
- [ ] PROGRESS
- [ ] NONE / STANDARD / PREMIUM
- [ ] 来場履歴
- [ ] パスワード非表示

## PROGRESS
- [ ] 一覧からメンバー選択
- [ ] プリセット
- [ ] 任意入力
- [ ] 理由
- [ ] 確認
- [ ] progressLogs
- [ ] adminLogs

## SIGNAL
- [ ] アーティスト一覧選択
- [ ] 送信者表示
- [ ] 3種別
- [ ] コメント表示
- [ ] 論理削除
- [ ] 復元
- [ ] 削除済み切替

## 変更履歴
- [ ] 主要操作を記録
- [ ] 読み取り専用
- [ ] 日時・管理者・対象・詳細

## レスポンシブ
- [ ] PC
- [ ] タブレット
- [ ] スマートフォン
